系统流程
	启动前:
		构造函数管理对象
		构造符号表对象
		注册预实现函数
		
	启动时:
		构造计算器类型
			初始化界面
			检测配置文件
				存在：加载DLL
			更新界面函数列表
			构造扫描器
			绑定界面按钮
	运行时:
		表达式计算
		或
		函数注册
			手动def定义
			加载DLL
		结果显示

构造函数管理对象:普通函数表和特殊函数表
构造符号表对象:默认为空
注册预实现函数:
	向普通函数表中插入字符串与函数指针

表达式计算:
	将字符串发送给扫描器，进行词法分析和语法分析
		由词法分析，获得标识符、字面值，获取当前语法最小操作对象
		由语法分析，识别为函数调用、二元操作、字面值，生成语法树
	
	函数调用将对各参数求值
	二元操作对左右操作数求值

加载DLL:
	读取dll文件，尝试获取其中giveName函数
	调用giveName函数，获取所有待加载函数
	向函数管理对象中插入字符串与函数指针
	更新函数列表

手动def定义:
	根据词法、语法分析，获取函数名、参数名、参数类型、函数体
	将参数名注册至变量表
	将函数名与函数体注册至特殊函数表
	将函数名添加至普通函数表，并设函数体为空;
	更新函数列表

结果显示:
	运算结果值为值对象，具有值类别和计算值
	当出错时，界面显示错误信息
	否则，显示计算值

表达式:
	函数名与调用操作
	操作数 与 操作符的序列
	被括号包围的符号序列
调用操作:
	被,分隔的操作数
操作数:
	表达式的求值结果
	标识符的求值结果
	字面值
操作符:
	"+ - * /"
	函数标识符

维持的符号表:
	内置函数标识符
	用户注册函数标识符
	第三方dll中包含的函数标识符
	变量名
