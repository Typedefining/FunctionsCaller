预实现函数接口规范：
return-type: FCMarks::FCValue 
functionname: [A-Za-z]+
arguments-list: std::vector<std::unique_ptr<FCExprClass::FCExprAST>>*

内部动态注册函数定义规范:
def ${functionname}(${arg1}:${type},${arg2}:${type})
registered-function-name(arg,arg,arg);

外部DLL实现规范
导出规范:
extern"C" {
	FCMarks::FCValue DLL testSub(void* any);
	DLL void giveName(void*);
}
函数规范:
	必须具有void giveName(void*)函数，该函数用于获取本DLL中所有被注册函数
		其中，void*指代外部
			::std::vector<::std::string>*

	被注册函数必须具有FCMarks::FCValue(void*)类型
		其中，void*指代外部
			std::vector<::std::unique_ptr<FCExprClass::FCExprAST>>*

giveName的实现可以为：
	dll中存储一个vector，具有本DLL中所有函数名字
	定义中：
		将该vector逐个拷贝至外部vector中
